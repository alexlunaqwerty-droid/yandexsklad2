# Проект Яндекс Склад · Площадки

![Предпросмотр (демо-данные)](docs/preview.png)

Сайт-дашборд по площадкам проекта Яндекс Склад: лиды на стажировку, выходы исполнителей, оборот и заработок исполнителей. Всё показано по дням и по площадкам. Это чистые HTML, CSS и JavaScript без сборки, поэтому сайт сразу работает на GitHub Pages.

Данные берутся из двух Google-таблиц:

- **«Списки Обучения Бизнес Ресурс»**: лиды (колонка «дата стаж») и пришедшие на стаж (в колонке «Комментарий» стоит «прошел»).
- **«Сверка по проекту»**: выходы (колонка «Операционный день»), оборот (колонка «Сумма») и заработок исполнителя («Сумма» ÷ 1,82).

## Как это устроено

```
Google-таблицы (закрыты)  →  Apps Script (считает итоги)  →  JSON  →  сайт на GitHub Pages
```

Таблицы остаются закрытыми. Скрипт Apps Script работает от имени владельца, читает только нужные колонки и отдаёт **готовые суммы по дням и площадкам**. ФИО, телефоны, даты рождения и логины на сайт не попадают.

> Если открыть сами таблицы по ссылке и читать их напрямую с сайта, любой посетитель сможет скачать персональные данные кандидатов. Поэтому сделано через Apps Script.

## Структура

```
index.html               страница
assets/css/styles.css    оформление (цвета и шрифты — в начале файла)
assets/js/config.js      настройки: адрес API, период по умолчанию, коэффициент
assets/js/api.js         загрузка данных и демо-режим
assets/js/charts.js      диаграммы, рейтинг, тепловые таблицы, схема площадок
assets/js/format.js      форматирование чисел и дат
assets/js/app.js         логика страницы
apps-script/Code.gs      серверная часть для Google Apps Script
apps-script/appsscript.json  манифест (часовой пояс Москва)
```

## Запуск за 10 минут

### 1. Создайте API в Apps Script

1. Зайдите на [script.google.com](https://script.google.com) под аккаунтом, у которого есть доступ к обеим таблицам, и нажмите **«Новый проект»**.
2. Замените содержимое `Code.gs` на файл `apps-script/Code.gs` из репозитория.
3. Откройте **Настройки проекта** (шестерёнка) и выберите часовой пояс **(GMT+03:00) Москва**.
4. Выберите в списке функцию `testBuild` и нажмите **«Выполнить»**. Google попросит разрешение на чтение таблиц — дайте его. В журнале появится число найденных дней. Если какой-то лист не найден, он будет указан там же.
5. Нажмите **«Развернуть» → «Новое развёртывание» → тип «Веб-приложение»**:
   - «Выполнять от имени» — **Я**;
   - «У кого есть доступ» — **Все**.
6. Скопируйте адрес вида `https://script.google.com/macros/s/…/exec`. Если открыть его в браузере, должен появиться JSON с `"ok": true`.

### 2. Подключите сайт

Откройте `assets/js/config.js` и вставьте адрес:

```js
API_URL: 'https://script.google.com/macros/s/…/exec',
```

Пока `API_URL` пустой, сайт показывает **выдуманные демо-данные** с пометкой об этом. Так удобно проверить, как всё выглядит.

### 3. Опубликуйте на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него все файлы.
2. Зайдите в **Settings → Pages**: Source — **Deploy from a branch**, Branch — **main**, папка **/ (root)**.
3. Через минуту сайт откроется по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

### Проверка на своём компьютере

Скрипты подключаются как модули, поэтому файл нельзя открыть двойным кликом. Нужен простой сервер:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Обновление данных

- Сайт загружает данные при открытии и затем каждые 5 минут (`REFRESH_MINUTES`). Кнопка ↻ в шапке загружает их сразу, минуя кеш.
- Apps Script держит готовый ответ в кеше 5 минут (`CACHE_SECONDS` в `Code.gs`).

## Что можно настроить

| Что | Где |
|---|---|
| Список площадок и названия листов | `CONFIG.TRAINING_SITES` и `CONFIG.RECON_SITES` в `Code.gs` |
| Коэффициент заработка (1,82) | `RATE` в `Code.gs` и `config.js` |
| Как считается «пришёл на стаж» | функция `isPassed_` в `Code.gs` |
| Период по умолчанию | `DEFAULT_DAYS` в `config.js` |
| Цвета и шрифты | переменные в начале `styles.css` (светлая и тёмная темы) |

**После любой правки `Code.gs`** выпустите новую версию: **«Развернуть» → «Управление развёртываниями» → карандаш → «Версия: новая версия» → «Развернуть»**. Адрес при этом не меняется.

Если в таблице переименуют лист, исправьте поле `sheet` в `Code.gs`. Колонки скрипт ищет по заголовкам в первой строке, поэтому их можно переставлять.

## Важно про доступ

- Бесплатный GitHub Pages публикует только публичные репозитории. В коде нет ни паролей, ни персональных данных, но **итоговые цифры увидит любой, у кого есть ссылка на сайт или на API**.
- Если цифры нужно закрыть, есть такие варианты: GitHub Pages с ограничением доступа (GitHub Enterprise), Cloudflare Pages с Cloudflare Access или собственный хостинг с паролем.

## Правила подсчёта

- **Лид** — строка листа с заполненной «датой стажа». День лида — эта дата.
- **Пришёл на стаж** — в «Комментарии» есть «прошел» и нет «не прошел». Такие отметки, как «пришёл на стажировку» или «не явился», не считаются.
- **Выход** — строка сверки с заполненным «Операционным днём».
- **Оборот** — сумма колонки «Сумма». **Заработок исполнителя** — оборот ÷ 1,82.
- Даты раньше 2024 года считаются опечатками и не учитываются.
- «Итого в день» — сумма по всем площадкам за день. «Итого за период» — сумма по каждой площадке за выбранные дни.
